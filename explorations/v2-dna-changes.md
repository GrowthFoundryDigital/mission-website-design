# Version 2 boards: what changes from version 1

Lanes C to G each have a version 1 and a version 2. Version 1 is the board as it stood on 26 Oct 2026, with every revision Growth Foundry made on the canvas. Version 2 starts as an exact copy of version 1, so those revisions carry over, and then changes only what the updated Business DNA (`business-dna-2026-10.md`) requires, plus a new case studies section. Layout, type, color, imagery and section order stay the same unless a change below needs room.

The DNA wins over `content-baseline.md` wherever they disagree.
